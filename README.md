# 📊 HR Analytics Dashboard | Power BI

An interactive Power BI dashboard developed to analyze workforce composition, employee attrition, salary, job satisfaction, performance, overtime, tenure, and work-life balance.

## 📌 Key Metrics

- 👥 1,470 Employees
- 🟢 1,233 Current Employees
- 🔴 237 Attrition Cases
- 🏢 3 Departments
- 💼 9 Job Roles

## 🔍 Analysis Areas

- Employee Attrition Analysis
- Workforce Composition
- Salary Analysis
- Job Satisfaction
- Performance Analysis
- Overtime Analysis
- Employee Tenure
- Work-Life Balance

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX
- Power Query
- Data Transformation
- Data Modeling
- KPI Development
- Data Visualization
- Dashboard Development

## 📈 Project Objective

The objective of this dashboard is to transform HR data into an interactive reporting solution that helps identify workforce patterns, understand employee attrition, and evaluate key HR performance indicators.
